# Layers
Download the layers from [Data WA](https://data.wa.gov.au/) and store in this folder the following:

* [Road_Network.geojson](https://catalogue.data.wa.gov.au/dataset/mrwa-road-network)
* [LGA_Boundaries_LGATE_233_WA_GDA2020_Public.geojson](https://catalogue.data.wa.gov.au/dataset/local-government-authority-lga-boundaries)
* [DFES_Stations_DFES_023_WA_GDA2020_Public.geojson](https://catalogue.data.wa.gov.au/dataset/dfes-stations) (Data WA DFES Stations DFES-023)
* `WAPoliceForceFacilities_SHP/` — stored locally and gitignored. This repo does not give it a catalogue link.
